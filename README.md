# MNIST Digit Classifier

A handwritten digit classification project using Perceptron, ANN, and CNN on the MNIST dataset.

## Models

- Perceptron
- Artificial Neural Network (ANN)
- Convolutional Neural Network (CNN)

## Technologies

- Python
- NumPy
- Pandas
- TensorFlow / Keras
- Scikit-learn
- Streamlit
- Matplotlib
- Jupyter Notebook

## Project Workflow

1. Load and preprocess the MNIST dataset
2. Train Perceptron, ANN, and CNN models
3. Evaluate the models
4. Save the trained models
5. Build a Streamlit frontend
6. Upload a handwritten digit and get a prediction

## Run the App

```bash
pip install -r requirements.txt
streamlit run app.py
